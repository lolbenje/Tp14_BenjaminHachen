Glosario de Conceptos de la Materia

Acumuladores

Es un tipo de variable que nos permite acumular/sumar valores/variables. Tiene este formato: acum=acum + variable

alert()

Función de JavaScript que muestra una ventana emergente con un mensaje en el navegador.

Algoritmo

Una serie de pasos ordenados y claros que se deben seguir para resolver un problema o cumplir un objetivo.

Archivo

Es la unidad básica de almacenamiento. Todo lo que existe digitalmente, está dentro de un archivo.

Archivo.bat

Es tipo específico de script para windows que al iniciarlo ejecuta una lista de comandos en el CMD.

Bloque

En programación visual (como Scratch), es la pieza gráfica que representa una instrucción o comando.

Bucle

Una estructura que repite un bloque de instrucciones varias veces o de forma infinita, mientras se cumpla una condición, evitando tener que escribir el mismo código una y otra vez.

Carpeta

Un contenedor virtual que sirve para organizar y agrupar archivos u otras carpetas.

Ciclo

Estructura que repite un bloque de código mientras se cumpla una condición o una cantidad determinada de veces.

CMD

Es una interfaz de texto que permite darle órdenes directas a la computadora, únicamente escribiendo comandos en el teclado.

Comando

Es una palabra o instrucción específica que escribes en la computadora para que realice una acción.

Condicional

Una estructura lógica que le permite a un programa tomar decisiones. Si se cumple una condición, el programa hace una cosa; si no se cumple, hace otra.

console.log()

Método de JavaScript que imprime mensajes o valores en la consola del navegador para probar y depurar código.

Constante

Espacio de almacenamiento que guarda información que no varía ni cambia durante la ejecución de un programa.

Contadores

Tipo de variable que nos permite contabilizar alguna variable en específico. Tiene este formato: cont=cont+1

Copy

Comando que se usa para copiar uno o más archivos de un lugar a otro, manteniendo el original intacto.

CSS

Es el lenguaje de diseño que se usa para darle aspecto visual, estilo y formato a la estructura que creamos con HTML.

document

Objeto en JavaScript que representa la página web cargada y permite acceder o modificar su contenido HTML.

Echo

Comando que se usa para escribir un texto dentro de el CMD o para escribir un texto dentro de un archivo.

else

Bloque que acompaña a un condicional para ejecutar un código alternativo cuando la condición no se cumple.

Evento

Una acción o suceso que ocurre en el navegador (como un clic, pulsar una tecla o cargar la página) al que el código puede reaccionar.

Extensión

Son las letras que van al final de un archivo luego de el “.” que le dicen al sistema operativo que tipo de archivo es y con qué programas puede abrirlo.

for

Tipo de bucle muy usado para repetir un bloque de código un número exacto de veces.

Función

Bloque de código reutilizable diseñado para realizar una tarea específica cuando se lo llama.

getElementById()

Método de document que busca y selecciona un elemento HTML específico según su atributo id.

Git

Sistema de control de versiones que permite registrar los cambios en los archivos de un proyecto a lo largo del tiempo.

GitHub

Plataforma web en la nube que permite alojar repositorios de Git y facilitar el trabajo colaborativo en proyectos de código.

Google drive

Es un servicio de almacenamiento en la nube, que te permite guardar o crear archivos ahí y acceder a ellos desde cualquier lugar.

HTML

Es el lenguaje que se utiliza para estructurar y organizar el contenido de una página web, le dice al navegador qué elementos hay en la pantalla (un título, un párrafo, una imagen, un botón).

IDE

Es un programa especializado que usan los programadores para escribir código. A diferencia de un bloc de notas común, un IDE incluye herramientas avanzadas en un solo lugar.

if

Palabra clave de un condicional que evalúa una condición y ejecuta un bloque de código solo si es verdadera.

JavaScript

Este sí es un lenguaje de programación real. Se encarga de darle interactividad, a una página web, permitiendo que responda a las acciones del usuario.

Math.random()

Función de JavaScript que devuelve un número decimal pseudoaleatorio entre 0 (incluido) y 1 (excluido).

Mkdir

Es un comando usado para crear una carpeta en la dirección actual.

prompt()

Función de JavaScript que muestra una ventana emergente con un campo de texto para que el usuario ingrese un dato.

PSlent

Una herramienta educativa diseñada para aprender los fundamentos de la programación utilizando pseudocódigo.

Repositorio

Espacio de almacenamiento o carpeta especial donde se guardan todos los archivos, historial de versiones y documentos de un proyecto.

Scratch

Un entorno de programación visual diseñado para aprender a programar sin lidiar con los errores de sintaxis del código escrito. Se programa encastrando bloques de colores.

Script

Un archivo de texto que contiene una lista de comandos ordenados.

Trabajo colaborativo

La modalidad de trabajo donde varias personas intervienen en un mismo proyecto o documento en tiempo real a través de internet, aportando ideas y editando de forma simultánea.

Variable

Espacio de memoria que guarda información que puede variar durante la ejecución de un programa.
